# Grist Location Manager v1

Link this custom widget to your Location Inventory widget using Select By.

It creates child locations under the currently selected parent, so you never need to search/type ParentLocationID.

Supported:
- Box rows/columns
- Freezer/Fridge temperature
- Freezer/Fridge/Rack/Cabinet shelf count with automatic child Shelf creation

Required location columns:
- ParentLocationID
- Type
- Name

Optional:
- Rows
- Columns
- Temperature_C
- NumberOfShelves

LocationID and Description are assumed to be generated by your Grist formulas/triggers.

Deploy as `location-manager/index.html` in your GitHub Pages repo and use a URL such as:
`https://YOURNAME.github.io/YOUR-REPO/location-manager/?v=1`
Set Full document access.
